# 화면: 검색 · 맛집 상세 · 그룹 선택

관련: `04-external-api.md` (호출·저장 규칙), `02-policies.md` 9절(맛집)

## 1. 통합 검색 — `MOOHAPP_SEARCH`

```text
[검색 전]                              [검색 결과]
+---------------------------------+    +---------------------------------+
| < [ 지역이나 음식점을 검색해 주세요]|    | < [ 신사                     (x)]|
| 최근 검색어            전체 삭제 |    | 총 5개                          |
| ○ 을지로 맛집               [X]  |    | [아이콘] 신사역 스시냥냥   [저장]|
| ○ 홍대 카페                 [X]  |    |          일식 · 신사            |
+---------------------------------+    +---------------------------------+
```

| 영역 | 구성 | 동작 |
|---|---|---|
| 검색창 | 인풋, clear 아이콘 | 공백 제거 후 1자 이상. 입력 시 clear 노출 |
| 최근 검색어 | 최대 10개, 최신순 | 개별 `[X]`, 전체 삭제. 같은 검색어 재검색 시 맨 위로 |
| 결과 | 기본 이미지/카테고리 아이콘, 맛집명, 카테고리, 지역, 저장 상태 (거리 없음) | 카드 → 맛집 상세 |
| 저장 | 북마크 아이콘 | → 그룹 선택 BS |
| 빈 화면 | 캐릭터 + 문구 | 0건 시 |

- 검색 대상: 상호명, 지역명, 역명, 주소, 카테고리
- 디바운스 또는 검색 완료 액션으로 호출
- 지역·역명으로 검색하면 그 지역 맛집이 결과로 나온다. 별도 지역 결과 · 지도 이동 없음 (D66)
- 상세에서 돌아오면 검색어·결과·스크롤 유지

## 2. 맛집 상세 — `MOOHAPP_PLACE_DETAIL`

```text
+-----------------------------------+
| < [홈]                      [공유]|
| [     기본 이미지 / 카테고리      ]|
| 평거린양꼬치 신사점        [저장] |
| 양꼬치 · 신사                     |
| [주소] 서울 강남구 ...      (복사)|
| [전화] 02-0000-0000               |
| [        미니 지도               ]|
| [      카카오맵으로 길찾기        ]|
| [ 카카오맵에서 사진·영업시간 보기 ]|
+-----------------------------------+
| [전화] [            저장          ]|
+-----------------------------------+
```

| 영역 | 구성 | 동작 |
|---|---|---|
| 헤더 | 뒤로, 홈, 공유 | 공유 → OS 공유 시트 (카카오맵 장소 링크) |
| 대표 이미지 | **기본 이미지 또는 카테고리 아이콘** | 사진은 API 미제공 |
| 기본 정보 | 맛집명, 카테고리, 지역 | 우측 저장 아이콘은 저장 상태와 동기화 |
| 주소 | 도로명 주소(없으면 지번) | 터치 → 복사, `MOOHAPP_TOAST_ADDRESS_COPY` |
| 전화 | 전화번호 | 있을 때만 노출. 터치 → 전화 연결 확인 |
| 지도 | 미니 지도 | 위치 확인용 |
| 길찾기 | `카카오맵으로 길찾기` | 카카오맵 앱 길찾기, 미설치 시 웹. 실패 시 `MOOHAPP_TOAST_KAKAOMAP_FAIL`, 상세 유지 |
| 카카오맵 보기 | `카카오맵에서 사진·영업시간 보기` ⚠️문구 | `place_url`을 카카오맵 앱/웹으로 열기 |
| 하단 CTA | 전화(보조 아이콘) + 저장(Primary) | 저장 → 그룹 선택 BS |

- **영업시간·영업 중/종료 표시 없음** (API 미제공)
- 이미 저장된 맛집이면 하단 버튼 `저장됨`, 터치 시 저장된 그룹이 체크된 그룹 선택 BS
- 좌표와 주소가 모두 없으면 지도·길찾기 미노출
- 상세 진입 시 장소가 확인되지 않으면(폐업 등) 상세 대신 `MOOHAPP_TOAST_PLACE_LOAD_FAIL` 후 이전 화면 (D38)
- 외부 앱에 갔다 돌아오면 상세 상태 유지

## 3. 그룹 선택 바텀시트 — `MOOHAPP_GROUP_SELECT_BS`

```text
+-----------------------------------+
| 그룹에 저장                    [X]|
| [IMG] 까치산 맛집          ( )    |
|       멤버 8 · 맛집 18            |
| [IMG] 낙성대입구...        (v)    |
|       멤버 1 · 맛집 157           |
| [IMG] 신사역 맛집     (100/100 비활성)|
| [+] 새 그룹 만들기                |
| [             완료             ]  |
+-----------------------------------+
```

| 영역 | 구성 | 동작 |
|---|---|---|
| 그룹 목록 | 커버, 그룹명, 멤버 수·맛집 수, 체크 | 다중 선택. 이미 저장된 그룹은 체크된 상태로 시작 |
| 새 그룹 | `[+] 새 그룹 만들기` | → 새 그룹 만들기. 그룹 수 상한(기본 5개) 도달 시 `MOOHAPP_DIALOG_GROUP_LIMIT` |
| CTA | `[완료]` | 체크 변경사항을 서버에 반영 |

- 그룹 0개면 목록 없이 새 그룹 만들기만 노출
- 새 그룹 생성 후 돌아오면 그 그룹 자동 체크
- 맛집 상한(기본 100개) 도달 그룹은 체크 불가 + 안내 (`MOOHAPP_TOAST_GROUP_PLACE_LIMIT`)
- 전부 체크 해제 후 완료 → 저장 해제 (`MOOHAPP_TOAST_PLACE_UNSAVE_SUCCESS`)
- 일부 그룹만 실패 시 성공분 유지, 실패분만 재시도
