# 화면: 진입 · 인증

관련 정책: `02-policies.md` 3절(계정·가입), 4절(앱 권한)

## 1. 스플래시 — `MOOHAPP_SPLASH`

```text
+-----------------------------------+
|          [모오 캐릭터]             |
|                    [위치 핀]      |
|        귀엽고 쫀득한              |
|        아궁빵 찾기!               |
|    MOOH: 같이 모으는 우리만의 맛집 지도 |
+-----------------------------------+
```

| 영역 | 구성 | 동작 |
|---|---|---|
| 브랜드 비주얼 | 모오 캐릭터·위치 핀 | 로딩 중 레이아웃 고정 |
| 카피 | 메인/서브 카피 | CTA 없음 |

- 앱 초기화 + 세션 확인 후 자동 이동
  - 초대 링크로 실행 → 링크 상태 확인 (`invite.md`)
  - 세션 유효 → 홈
  - 세션 없음 → 온보딩 완료 여부에 따라 온보딩 또는 로그인
- 초기화 실패가 오래 지속되면 네트워크 재시도 화면

## 2. 온보딩 — `MOOHAPP_ONBOARDING`

```text
[PAGE 1]                          [PAGE 2]
+-------------------------+       +-------------------------+
|   [맛집 이미지 Full]     |       |  [함께 보는 이미지 Full] |
| 나만의 맛집은            |       | 친구와 함께              |
| 저장해 두세요.           |       | 맛집을 모아요.           |
| 작은 설명 문구           |       | 공유 그룹 설명           |
| [        다음         ] |       | [       시작하기       ] |
+-------------------------+       +-------------------------+
```

| 영역 | 구성 | 동작 |
|---|---|---|
| 배경 | 풀 이미지 | 하단 Dim/Gradient로 텍스트 가독성 확보 |
| 본문 | 메인·서브 카피 | 좌측 정렬 |
| CTA | 1페이지 `다음`, 2페이지 `시작하기` | 완료 시 로그인으로 |

- 최초 설치 후 1회만 노출, 완료 여부는 기기에 저장

## 3. 로그인 — `MOOHAPP_LOGIN`

```text
+-----------------------------------+
|              MOOH                  |
|     같이 모으는 우리만의 맛집 지도 |
|       [캐릭터 + 지도 비주얼]      |
|      SNS 계정으로 간편 로그인     |
|  [카카오] [네이버] [Apple] [Google]|
| 로그인 시 이용약관 및 개인정보... |
+-----------------------------------+
```

| 영역 | 구성 | 동작 |
|---|---|---|
| 브랜드 | 로고·서비스 설명 | 상단~중앙 |
| 소셜 로그인 | 원형 버튼 4개 | 카카오 → 네이버 → Apple → Google 순. 터치 시 provider 인증 |
| 고지 | 약관·개인정보 문구 | 텍스트 링크 |

- 인증 성공: 신규 계정 → 약관 화면 / 기존 계정 → 홈. 비밀 초대장에서 왔으면 로그인(신규면 약관까지) 완료 직후 그 그룹 참여 처리 → 그룹 상세 (D29)
- 인증 취소: 화면 유지 / 실패: `MOOHAPP_TOAST_LOGIN_FAIL`
- 인증 진행 중 다른 버튼 비활성
- 계정 병합 없음: 다른 provider로 로그인하면 새 계정

## 4. 신규 가입 약관 — `MOOHAPP_SIGNUP_TERMS`

```text
+-----------------------------------+
|              신규 가입        [X] |
|          [모오 캐릭터]             |
| 서비스 이용을 위해                |
| 약관에 동의해 주세요              |
| ( ) 전체 동의                     |
| --------------------------------- |
| ( ) 만 14세 이상입니다 (필수)      |
| ( ) 이용약관 동의 (필수)        > |
| ( ) 개인정보 수집 및 이용 (필수) > |
| [             확인             ]  |
+-----------------------------------+
```

| 영역 | 구성 | 동작 |
|---|---|---|
| 헤더 | 타이틀·닫기 | `[X]` → 가입 중단, 로그인 화면 |
| 전체 동의 | 체크박스 | 하위 항목 일괄 선택/해제 |
| 연령 확인 | `만 14세 이상입니다 (필수)` | 행 터치 → 체크. 전문 보기 없음 |
| 개별 약관 | 필수 2개(이용약관 · 개인정보). 선택 약관 없음 (D53) | 행 터치 → 체크, `>` → 전문 보기 (블로그 글과 같은 내용, D58) |
| CTA | `[확인]` | 필수 3개(연령 확인 포함) 동의 시 활성 |

- **만 14세 미만은 가입 불가.** 연령 확인 미체크 시 `[확인]` 비활성 (법정대리인 동의 절차는 두지 않음)
- 선택 약관 없음 (D53 · D66)
- 전문 보기에서 돌아오면 체크 상태 유지
- 마케팅·알림 수신 동의 항목은 **현재 없음** (`open-questions.md`: 유료 BM)
- 가입 완료 시 랜덤 닉네임 `모오` + 숫자 4자리, 기본 프로필 이미지 (D81). 소셜 계정의 이름 · 사진은 받지 않음 → 마이 > 프로필 수정에서 변경
