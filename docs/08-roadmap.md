# 08. 전체 로드맵 (MVP 기준)

> 갱신 2026-11-19 · 근거: `decisions.md` D51~D65
> 공개된 법령 · 정부 발표 · 스토어 정책을 정리한 일반 정보이며 법률 자문이 아니다. 해석이 애매하면 KISA(국번 없이 118)에 확인.

- 이름: 영문 **MOOH** · 로고 **MOO-H** · 한글 **모오호** (메인 캐릭터 모오) — D64
- 목적: 1순위 경험, 2순위 포트폴리오(지정한 곳에만 전달) → 취업 → 이후 출시
- MVP: **iOS만**(D52) · **Oracle Cloud 무료 서버, 춘천/서울 리전**(D63) · 소셜 로그인 전용(구글/애플/네이버/카카오) · **앱 권한 요청 없음**(D54) · 앱 안 AI 없음 · 앱 밖 푸시 없음(알림함만)

## MVP에서 제외 (7단계 이후) — D51
- Android 출시
- 포오호 · 초오호 캐릭터 상표 출원
- 지연 딥링크 (설치 직후 자동 초대장)

## 서버 (D63)
- **Oracle Cloud Always Free** — Arm(Ampere A1) 1대, 무료 한도 합계 2 OCPU · 12GB(2026-06 축소 후). 한 대에 API + DB + 사진 파일 + `config.json`
- 홈 리전 **춘천 또는 서울** (한 번 고르면 변경 불가) → 국외이전 없음
- 처리방침: "수탁자 Oracle Corporation / 서버 및 데이터 보관 / 보관 위치 대한민국"
- 주의: 한국 리전 무료 자원이 없으면 "Out of capacity" → 며칠 재시도 · 가입 시 카드 등록(본인 확인) · 무료 한도 넘는 자원 만들지 않기 · 오래 놀리면 회수될 수 있음

## 1. 인프라 구축
1. Oracle Cloud 서버
   - 가입(홈 리전 춘천/서울) → **예산 알림**(0원 넘으면 메일)
   - Ampere A1 1대(2 OCPU · 12GB 이하), 무료 블록 스토리지 합계 200GB 안
   - 방화벽 80 · 443만, SSH 키 로그인만
   - DB는 외부 접속 차단, Nginx + HTTPS(Let's Encrypt)
   - 도메인 **본인 명의**(API · `config.json`용 — 초대 랜딩 없음, D55)
   - DB · 사진 **매일 자동 백업**(서버 밖 한 곳에도)
2. Apple Developer 가입, **번들 ID 확정**(MOOH 기준, 한 번 올리면 못 바꿈)
3. 카카오(REST 키 · 네이티브 키 · **카카오톡 공유** 사용 설정) · 네이버 · 구글 로그인 키 발급. **카카오 좌표 저장 허용 확인**(D35, 확인 전 개발 착수 금지)
4. 네이버 블로그에 정책 문서 · 공지 카테고리 (댓글 · 공감 끔) — D57 · D58
5. MOOH 전용 이메일 · 인스타그램 계정 (협업 문의, D59)

## 2. 디자인시스템 정리 → AI 학습
6. 이름 표기 MOOH / MOO-H / 모오호로 통일
7. 캐릭터 원본 이미지 파일 저장, 날짜가 남게 백업
8. 폰트 · 이미지 이용권 목록 (Pretendard OFL ✅, SF Symbols 로고 사용 금지)

## 3. 기획 / 기능명세 → 바이브 코딩
9. 하단 탭 **홈 / 그룹 / 마이** 3개 (D51)
10. 가입 약관 필수 3개, 선택 없음 (D53)
11. 앱 권한 요청 없음, 검색 거리 미표시 (D54)
12. 홈 배너: 원격 설정 JSON, 운영자 2~3개 등록, 대가 받은 배너는 "광고" (D50 · D60)
13. 공지사항 = 블로그 링크 / FAQ = 앱 화면(원격 JSON) (D57)
14. 협업 문의 = 인스타 DM 또는 전용 이메일 (D59)
15. 폐업 맛집: 서로 다른 날 연속 2회 미확인 시 자동 삭제(D14, 플래그 D36) → 그룹 멤버 전원 **알림함** `NOTI_PLACE_AUTO_REMOVED` (D56)
16. 초대: 카카오톡 공유 + 앱 실행 파라미터(토큰) → 앱 있으면 바로 초대장 / 없으면 App Store → 설치 · 가입 후 메시지 다시 눌러 참여 (D55)
17. 탈퇴: 즉시 파기 + Apple 토큰 revoke + 카카오 · 네이버 · 구글 연결 끊기 (D61)
18. 푸터: 운영자 이름 · 문의 이메일만 (D62)

## 4. 구축 + 테스트
19. 프론트 · 백엔드 · DB 구축 (원격 설정 · 알림함 `PLACE_AUTO_REMOVED` 포함)
20. 개인정보 매니페스트 · App Store 개인정보 라벨 (위치 미수집)
21. 테스트: 소셜 로그인 4종 + 연결 끊기, 탈퇴 후 실제 삭제, 카카오톡 초대(앱 있음/없음 · 로그인/비로그인), 폐업 2회 확인 · 알림함, 카카오맵 길찾기
22. TestFlight 테스트
23. **포트폴리오 전달 → 취업** (일반 공개 전이라 사업자등록 · 신고 문제 없음. 입사 후 출시 시 회사 겸업 규정 확인)

## 5. 앱 출시 (iOS)
