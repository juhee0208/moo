# 화면: 그룹

관련 정책: `02-policies.md` 5절(권한), 6절(그룹), 7절(초대), 8절(삭제·강퇴), 9.1절(폐업 자동 삭제)

## 1. 그룹 홈 — `MOOHAPP_GROUP_HOME`

```text
+-----------------------------------+
|               그룹                |
| 총 5개                 최근 수정순 v|
| [IMG] 까치산 맛집          [공유] |
|       까치산 맛집 모음            |
|       멤버 8 · 맛집 23   (아바타) |
| [IMG] 낙성대입구 맛집             |
|       멤버 1 · 맛집 32            |
|                         [+ 새 그룹]|
+-----------------------------------+
| 홈 | 그룹 | 마이                  |
+-----------------------------------+
```

| 영역 | 구성 | 동작 |
|---|---|---|
| 헤더 | 타이틀, 총 개수 | 만든 그룹 + 참여 그룹 수 |
| 정렬 | 드롭다운 | 최근 수정순(기본) / 그룹 이름순 / 그룹 인원순 / 저장순 |
| 그룹 카드 | 커버, 그룹명, 설명, 멤버 수·맛집 수, 아바타, 공유 배지(멤버 2명 이상) | 카드 → 그룹 상세. 그룹명 최대 2줄 또는 말줄임 |
| 길게 누르기 / 밀어서 삭제 | 생성자: `삭제` / 멤버: `나가기` | 각각 확인 Dialog (`GROUP_DELETE_CONFIRM` / `GROUP_LEAVE_CONFIRM`) |
| FAB | `[+ 새 그룹]` | → 새 그룹 만들기. 그룹 수 상한(기본 5개) 도달 시 `MOOHAPP_DIALOG_GROUP_LIMIT` |

- 최근 수정일 라벨(선택): 오늘 / 어제 / 2~7일 전 / 1~5주 전 / 1~12개월 전 / 1년 전 이상
- 0건: 캐릭터 빈 화면 + `[+ 새 그룹]`

## 2. 새 그룹 만들기 — `MOOHAPP_GROUP_CREATE`

```text
+-----------------------------------+
|             새 그룹           [X] |
|          [커버 이미지]            |
|          커버 이미지 선택          |
| 그룹명 (필수)                     |
| [ 그룹명 입력 (최대 15자)      0/15]|
| 설명 (필수)                       |
| [ 그룹 설명 입력 (최대 15자)   0/15]|
| 초대 링크                         |
| [ mooh.app/invite/...........  ]   |
| [          그룹 만들기          ] |
+-----------------------------------+
```

| 영역 | 필수 | 동작 |
|---|---|---|
| 커버 | 선택 | 앨범에서 선택. 미선택·업로드 실패 시 MOOH 기본 이미지로 계속 생성 |
| 그룹명 | 필수 | 1~15자, 공백만 불가, 이모지 허용 |
| 설명 | 필수 | 1~15자, 공백만 불가 |
| 초대 링크 | - | 진입 시 임시 토큰 발급·표시(읽기 전용). 생성 완료 시 활성 |
| CTA | - | 그룹명·설명 유효 시 활성. 요청 중 로딩·중복 터치 차단 |

- `[X]` → 확인 없이 이전 화면, 입력값·임시 토큰 폐기
- 생성 실패 시 입력값 유지 + `MOOHAPP_TOAST_GROUP_CREATE_FAIL`
- 생성 후: 그룹 홈에서 왔으면 그룹 상세 / 저장 중에 왔으면 그룹 선택 BS로 돌아가 자동 체크
- 생성한 사람이 생성자(OWNER)

## 3. 그룹 상세 — `MOOHAPP_GROUP_DETAIL`

```text
+-----------------------------------+
| <  [홈]               [공유][설정]|
| [          그룹 커버             ]|
| 데이트 코스                 [지도]|
| 홍대, 종로 일대 맛집              |
| [ 맛집 (23/100) ] [ 멤버 (3/20) ] |
| --------------------------------- |
| [아이콘] 신사역 스시냥냥    [저장]|
|          일식 · 신사              |
| [아이콘] 또래오래 신사역점  [저장]|
| [             맛집 추가          ]|
+-----------------------------------+
```

| 영역 | 구성 | 동작 |
|---|---|---|
| 헤더 | 뒤로, 홈, 공유(**생성자만 노출**), 설정 | 공유 → 친구 초대 화면 (D40). 설정 → 생성자: 그룹 수정 / 멤버: 그룹 나가기 메뉴 |
| 커버 | 대표 이미지 | 라운드 직사각 |
| 그룹 정보 | 그룹명, 설명, 지도 아이콘 | 지도 아이콘 → `MOOHAPP_GROUP_MAP`. `TODO`: 좌표 저장 허용 시에만 노출, 불허 시 아이콘 제거 (D39) |
| 탭 | `맛집 N/{max}` · `멤버 N/{max}` (기본 100 / 20) | 탭 전환. N은 숨긴 맛집 포함 서버 저장 수 (D37) |
| 맛집 탭 | 기본 이미지/아이콘, 맛집명, 카테고리·지역, 저장 아이콘 | 카드 → 상세. 삭제(생성자·멤버 모두 가능) |
| 멤버 탭 | 아바타, 닉네임, 역할 | 생성자 행에 `그룹장`. 생성자에게만 다른 멤버 `[내보내기]` |
| 하단 CTA | `[맛집 추가]` | 검색 또는 지도에서 선택해 이 그룹에 추가 |

- **맛집 탭은 20개씩 불러오며 그때마다 카카오 재조회** → 폐업 확인 (`02-policies.md` 9.1). 확인 안 된 맛집은 이번 화면에서는 숨김. 자동 삭제는 플래그 on 이후에만 (D36)
- 맛집 상한(기본 100개) 도달 → `[맛집 추가]` 비활성 + 안내
- 멤버 20명 도달 → 초대 화면에서 정원 안내
- 맛집 0건 → 캐릭터 빈 화면 + `[맛집 추가]`
- 보는 중에 그룹이 삭제됨 → 다음 갱신 때 `MOOHAPP_TOAST_GROUP_DELETED` + 이전 화면
- 보는 중에 내보내짐 → 다음 갱신 때 `MOOHAPP_DIALOG_GROUP_FORBIDDEN` → 그룹 홈
- 내보내기: 확인 Dialog → 직전 재검증 → 대상에게 알림함 항목 추가

## 4. 그룹 수정 — `MOOHAPP_GROUP_EDIT` (생성자 전용)

```text
+-----------------------------------+
|             그룹 수정         [X] |
|          [커버 이미지]            |
| 그룹명 (필수) [ 데이트 코스      ]|
| 설명 (필수)  [ 홍대, 종로 일대   ]|
| 초대 링크                         |
| [ mooh.app/invite/.... ] [재발급]  |
| [삭제 아이콘]                     |
| [              수정             ] |
+-----------------------------------+
```

| 영역 | 동작 |
|---|---|
| 커버·그룹명·설명 | 생성 규칙과 동일 |
| 초대 링크 | 복사 가능. `[재발급]` → 확인 Dialog → 기존 링크 무효 |
| 삭제 | 휴지통 → `MOOHAPP_DIALOG_GROUP_DELETE_CONFIRM` → 삭제 → 메시지 없이 그룹 홈 |
| CTA | 변경사항이 유효할 때 저장 |

- `[X]` → 확인 없이 닫기, 입력값 폐기
- 삭제 시 남은 멤버에게 알림함 항목 (`NOTI_GROUP_DELETED`, reason=`OWNER_DELETED`)

## 5. 친구 초대 — `MOOHAPP_GROUP_INVITE` (생성자 전용)

```text
+-----------------------------------+
|             친구 초대         [X] |
|          [그룹 커버]              |
|             데이트 코스           |
|     홍대, 종로 일대 맛집          |
|          [공유 배지]              |
| 함께 멤버                         |
| (나) (멤버) (멤버) ...            |
| 초대 링크                         |
| [ mooh.app/invite/........ ] [복사]|
| [            링크 공유하기       ]|
+-----------------------------------+
```

| 영역 | 동작 |
|---|---|
| 그룹 요약 | 커버, 그룹명, 설명, 맛집/멤버 수 |
| 멤버 | 아바타 목록 (최대 20) |
| 초대 링크 | 화면에 표시하지 않거나 상태만 표시(유효기간). 복사 기능 없음 — 카톡 메시지 버튼으로만 열리므로 (D55) |
| CTA | `[카카오톡으로 공유하기]` → 카카오톡 공유(초대 템플릿, 버튼에 `iosExecutionParams`=토큰). 메시지 문구에 "앱이 없다면 설치 후 이 메시지를 다시 눌러주세요" (D55) |

- **생성자만** 진입 가능 (D40). 멤버에게는 진입점을 노출하지 않음
- 진입 시 링크가 만료돼 있으면 자동으로 새 링크를 발급해 표시 (D41). 유효 링크를 강제로 무효화하는 수동 재발급은 그룹 수정에서
- 멤버 20명 도달 → `최대 인원 20명에 도달했어요.` ⚠️ 안내 + 공유 CTA 비활성
- 그룹 삭제·권한 해제 상태로 진입 → 그룹 홈
