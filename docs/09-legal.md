# 09. 법 · 스토어 심사 · 상표 체크리스트

> 갱신 2026-11-25 · MVP(iOS, 위치 미사용) 기준. 법률 자문이 아니며, 해석이 애매하면 KISA(118) · 특허청 고객상담센터(1544-8080)에 확인.
> 순서는 `08-roadmap.md`, 결정 근거는 `decisions.md`.

## 1. 개인정보 보호법
- [ ] **개인정보처리방침** — 앱 안 + 네이버 블로그 공개 글 (D58). 수집 항목: 소셜 식별값 · 닉네임(랜덤 부여, D81) · 약관 동의 기록 · 그룹/저장 맛집 · 세션 · 선택 사진(EXIF 제거, D68). 이메일 · 이름 · 소셜 프로필 사진 미수집, 위치 미수집
- [ ] 보호책임자(본인) · 문의 이메일 · 시행일 채우기
- [ ] **위탁**: 수탁자 Oracle Corporation(OCI), 업무 = 서버 및 데이터 보관, 보관 위치 대한민국 → 국외이전 없음 (D63)
- [ ] 외부 제공 · 전송: 카카오(장소 검색 · 공유) · 소셜 로그인 사업자
- [ ] **만 14세 미만 가입 불가** (필수 약관, D53)
- [ ] 탈퇴 시 지체 없이 파기 (D61)
- [ ] 유출 시 **72시간 안** 신고 · 통지. 2026-09-11부터 과징금 상한 매출의 최대 10%
- [ ] 최소 수집: 소셜 로그인 이메일 · 생일 · 이름 · 프로필 사진 받지 않기 (D81)

## 2. 정보통신망법
- [ ] 앱 접근권한 필수/선택 구분 고지(제22조의2) — MVP는 **요청 권한 없음**(D54), 사진은 PhotosPicker
- [ ] 광고성 메시지 보내지 않음 (마케팅 수신 동의 항목 없음). 보내게 되면 "(광고)" · 수신거부 · 야간 동의 적용

## 3. 위치정보법
- [ ] **해당 없음** — 위치 정보를 수집하지 않음 (D66). 앱에 위치 권한 문구 · 코드 · 약관이 남아 있지 않은지 확인

## 4. 표시 · 저작권
- [ ] 배너 이미지 이용권, 대가 받은 배너 "광고" 표시, 근거 없는 광고 문구 금지 (D60)
- [ ] 폰트(Pretendard OFL) · 아이콘 이용권, SF Symbols 로고 사용 금지, 상표가 보이는 사진 금지
- [ ] 오픈소스 라이선스 고지 화면 (환경설정, D84)
- [ ] 지도 저작권 표시(카카오맵 로고 등) 가리지 않기 — MVP는 지도 없음(D85), 그룹 지도 구현 시
- [ ] 카카오 로컬 API 약관: 응답 저장 금지, 좌표 저장 허용 확인(D35)
- [ ] 푸터: 운영자 이름 · 문의 이메일 (D62). 유료화 · 판매 시 사업자 정보 · 통신판매업 신고번호

## 5. AI 관련
- [ ] 앱 안 AI 기능 없음 → AI 기본법 고지 의무 해당 없음
- [ ] 캐릭터는 ChatGPT로 생성: 원본 이미지 파일을 날짜와 함께 보관, 상표로 보호(저작권 등록은 AI 생성물이라 어려움)

## 6. App Store 심사
- [ ] 개인정보처리방침 URL · 지원 URL (블로그 글)
- [ ] **Sign in with Apple** 포함 (다른 소셜 로그인과 함께)
- [ ] 앱 안 회원 탈퇴 + **Apple 토큰 revoke** (5.1.1(v)) + 카카오 · 네이버 · 구글 연결 끊기 (D61). 토큰은 탈퇴 때 재로그인으로 받음 (D82)
- [ ] 개인정보 매니페스트 `PrivacyInfo.xcprivacy` · 개인정보 라벨 일치 (추적 없음, 위치 미수집 — 업로드 사진의 EXIF 위치도 제거, D68)
- [ ] 연령 등급 설문 (초대받은 사람끼리만 보는 그룹 — 공개 사용자 콘텐츠 없음)

- [ ] 개발용 로그인 · 샘플 데이터 Release 빌드에서 제거
