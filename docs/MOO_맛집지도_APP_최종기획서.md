# MOO 맛집 지도 APP 기획서 V2

> 서비스명: **MOO : 맛집 지도**  
> 플랫폼: **Mobile APP Only**  
> 문서 목적: 화면 시안 기준 기능·정책·상태·예외 처리 정의  
> 범위: iOS / Android APP, WEB 및 운영자 어드민 제외

---

# 1. 서비스 개요

## 1.1 서비스 정의

MOO는 사용자가 음식점을 지도에서 탐색하고 저장한 뒤, 목적에 따라 그룹으로 관리하고 친구와 함께 공유·편집할 수 있는 맛집 지도 APP이다.

## 1.2 핵심 가치

1. 지도에서 원하는 맛집을 빠르게 찾는다.
2. 마음에 드는 맛집을 바로 저장한다.
3. 저장한 맛집을 그룹별로 정리한다.
4. 친구와 그룹을 공유하고 함께 맛집을 추가한다.

## 1.3 서비스 콘셉트

- 토스, 배달의민족처럼 간결하고 기능 중심인 UI
- 복잡한 커뮤니티 기능 없이 탐색·저장·공유에 집중
- 밝고 친근한 브랜드 이미지
- 캐릭터는 온보딩 및 안내 영역에서 보조적으로 활용
- 핵심 행동은 최대 1~2단계 이내에 완료

# 4. 진입 및 인증

## 4.1 온보딩

### 목적

서비스 핵심 가치인 `맛집 탐색`, `저장`, `그룹 공유`를 간단하게 안내한다.

### 화면 구성

- MOO 캐릭터 또는 브랜드 이미지
- 메인 카피
- 서브 카피
- 페이지 인디케이터
- 다음 또는 시작하기 버튼

### 정책

- 최초 설치 후 첫 진입 시 노출
- 온보딩 완료 여부를 기기 또는 계정에 저장
- 완료 후 재실행 시 온보딩 생략
- 마이페이지에서 다시 보기 기능은 MVP 선택 사항

## 4.2 로그인

### 로그인 방식

- 카카오
- 네이버
- Apple
- Google

### 화면 구성

- MOO 로고
- 서비스 설명
- 소셜 로그인 버튼
- 이용약관 및 개인정보처리방침 동의 안내

### 정책

- 음식점 탐색은 비로그인 상태에서도 허용 가능
- 저장, 그룹 생성, 공유 및 공동 편집은 로그인 필수
- 로그인 화면 진입 시 마지막 요청 행동을 임시 저장
- 로그인 완료 후 원래 요청 화면으로 복귀

### 로그인 예외

- 인증 취소: 로그인 화면 유지
- 인증 실패: `로그인에 실패했어요. 잠시 후 다시 시도해 주세요.`
- 네트워크 오류: 재시도 제공

# 5. 홈

## 5.1 화면 목적

홈은 사용자가 검색, 추천 콘텐츠, 최근 그룹 및 최근 저장 데이터를 빠르게 확인하는 대시보드다.

## 5.2 화면 구성 순서

1. 웰컴 헤더
2. 통합 검색창
3. 프로모션 또는 추천 Hero Banner
4. 최근 그룹
5. 최근 저장한 맛집
6. MOO 안내 배너
7. 나와 함께하는 MOO 친구
8. 사업자 및 서비스 정보
9. 하단 내비게이션

## 5.3 웰컴 헤더

### 구성

- `WELCOME` 라벨
- 사용자 닉네임
- 인사 이모지
- 프로필 이미지

### 정책

- 닉네임 최대 노출 길이 설정
- 초과 시 말줄임 처리
- 프로필 이미지 미등록 시 기본 프로필 이미지 노출
- 프로필 이미지 선택 시 마이페이지로 이동

## 5.4 통합 검색창

### 플레이스홀더

`지역이나 음식점을 검색해 보세요.`

### 검색 범위

- 음식점명
- 지역명
- 역명
- 주소
- 음식 카테고리

### 동작

- 검색창 선택 시 검색 전용 화면으로 이동
- 홈에서는 키보드 및 결과 목록을 직접 노출하지 않음
- 검색 결과 선택 시 음식점 상세 또는 지도 위치로 이동
- 최근 검색어 최대 10개 저장
- 최근 검색어 개별 삭제 및 전체 삭제 제공

## 5.5 Hero Banner

### 목적

시즌별 맛집 콘텐츠나 지역 추천 콘텐츠를 노출한다.

### 구성

- 배경 이미지
- 카테고리 또는 캠페인 라벨
- 타이틀
- 서브 정보
- 선택 영역 전체 CTA

### 정책

- 배너는 한 번에 1개 노출
- 복수 배너 운영 시 자동 또는 수동 캐러셀
- 페이지 인디케이터 제공
- 배너 선택 시 연결된 검색 결과, 지도 또는 콘텐츠 상세로 이동
- 연결 대상이 없는 배너는 노출하지 않음
- 이미지 로딩 실패 시 기본 배경과 텍스트만 노출

## 5.6 최근 그룹

### 카드 구성

- 그룹 대표 이미지
- 그룹명
- 저장 음식점 수
- 공유 상태 배지
- 필요 시 멤버 프로필

### 노출 정책

- 최근 수정순
- 최대 3~5개 노출
- 가로 스크롤
- `더보기` 선택 시 저장 화면으로 이동
- 카드 선택 시 그룹 상세로 이동

### 공유 배지

- 공유 그룹에만 `공유` 배지 노출
- 개인 그룹에는 배지 미노출

### 대표 이미지 정책

1. 사용자가 지정한 커버
2. 그룹에 가장 최근 저장된 음식점 이미지
3. 기본 그룹 이미지

### 빈 화면

`아직 만든 맛집 그룹이 없어요.`

CTA: `새 그룹 만들기`

## 5.7 최근 저장한 맛집

### 카드 구성

- 음식점 썸네일
- 음식점명
- 카테고리
- 지역 또는 거리 정보
- 저장된 그룹 태그
- 저장 아이콘

### 노출 정책

- 최근 저장순
- 홈에는 최대 3~5개 노출
- `더보기` 선택 시 저장된 음식점 전체 목록으로 이동
- 저장 아이콘 선택 시 저장 그룹 편집 바텀시트 노출
- 카드 선택 시 음식점 상세로 이동

## 5.8 MOO 안내 배너

### 목적

서비스 이용 팁, 저장 유도, 그룹 공유 기능 등을 안내한다.

### 정책

- 프로모션 배너와 구분되는 안내형 인라인 배너
- 조건에 따라 노출 콘텐츠 변경 가능
- 배너 선택 시 해당 기능 화면으로 이동

## 5.9 나와 함께하는 MOO 친구

### 개념

친구 관계가 아니라, 동일 공유 그룹에 참여 중인 멤버를 의미한다.

### 구성

- 프로필 이미지
- 닉네임
- 함께 참여 중인 그룹 수

### 노출 정책

- 최근 공동 활동 기준 정렬
- 홈에는 최대 4~6명 노출
- 멤버 선택 시 함께 참여 중인 그룹 목록 또는 대표 그룹으로 이동
- 개인 프로필 상세는 MVP에서 제공하지 않음

### 빈 화면

공유 멤버가 없을 경우 영역을 숨기거나 초대 유도 배너로 대체한다.

## 5.10 사업자 및 서비스 정보

### 구성

- 서비스명
- 대표자
- 주소
- 사업자등록번호
- 통신판매업 신고번호
- 이메일
- 이용약관
- 개인정보처리방침
- 고객센터 또는 문의하기
- 저작권 문구

# 6. 내주변 지도

## 6.1 지도 기본 화면

### 구성

- 상단 검색창
- 음식 카테고리 칩
- 필터 버튼
- 지도
- 음식점 마커
- 저장 마커
- 현재 위치 버튼
- `이 지역 검색` 버튼
- 목록 보기 버튼
- 선택 음식점 카드
- 하단 내비게이션

### 기본 동작

- 위치 권한 허용 시 현재 위치 중심
- 위치 권한 미허용 시 최근 검색 지역 또는 기본 지역 중심
- 지도 이동 후 `이 지역 검색` 버튼 노출
- 버튼 선택 전에는 기존 결과 유지
- `이 지역 검색` 선택 시 현재 뷰포트 기준 결과 갱신

## 6.2 카테고리 칩

### 예시

- 전체
- 한식
- 양식
- 일식
- 중식
- 카페
- 기타

### 정책

- 기본값은 `전체`
- MVP에서는 단일 선택 권장
- 선택 시 지도 마커와 목록 결과 즉시 갱신
- 선택된 칩은 강조 상태

## 6.3 필터

### MVP 필터

- 저장한 맛집만
- 현재 영업 중
- 거리
- 음식 카테고리

### 정책

- 필터 버튼에 적용 개수 표시 가능
- 필터 적용 후 지도와 목록 결과 동기화
- 전체 초기화 제공

## 6.4 지도 마커

### 마커 상태

- 기본 음식점
- 저장한 음식점
- 현재 선택한 음식점
- 클러스터
- 사용자 현재 위치

### 저장 마커 정책

- 저장한 음식점은 별도 저장 아이콘 또는 컬러로 구분
- 동일 음식점이 여러 그룹에 저장되어도 마커는 1개만 노출

## 6.5 음식점 요약 카드

### 구성

- 썸네일
- 음식점명
- 음식 카테고리
- 거리 또는 도보 시간
- 주소 또는 지역
- 저장 버튼

### 동작

- 카드 선택 시 음식점 상세로 이동
- 저장 버튼 선택 시 그룹 선택 바텀시트 노출
- 이미 저장된 경우 저장됨 상태 노출

## 6.6 목록 보기

### 진입

지도 우측 하단 또는 플로팅 버튼의 `목록 보기` 선택

### 정책

- 지도와 동일한 검색 조건 유지
- 목록에서 음식점 선택 시 상세 화면 이동
- 지도 보기 복귀 시 기존 지도 위치 유지

## 6.7 지도 예외 처리

### 위치 권한 거부

- 기본 지역 지도 노출
- 현재 위치 버튼 선택 시 권한 안내
- 영구 거부 상태에서는 설정 이동 제공

### 현재 위치 확인 실패

`현재 위치를 확인하지 못했어요.`

### 지도 데이터 로딩 실패

`지도를 불러오지 못했어요.`

### 음식점 결과 없음

`이 지역에 표시할 음식점이 없어요.`

# 7. 음식점 검색

## 7.1 검색 화면 구성

- 검색 입력창
- 취소
- 최근 검색어
- 추천 검색어 또는 카테고리
- 검색 결과 목록
- 결과 없음 상태

## 7.2 검색 결과 카드

- 썸네일
- 음식점명
- 카테고리
- 지역
- 거리
- 저장 여부

## 7.3 검색 결과 선택

- 음식점 검색 결과: 상세 화면 이동
- 지역·역명 검색 결과: 해당 지도 위치로 이동
- 카테고리 검색 결과: 지도에 필터 적용 후 이동

## 7.4 검색 예외

- 공백만 입력: 검색 실행 안 함
- 최소 1자 이상 입력
- 연속 입력 시 디바운스 적용 권장
- 결과 없음: `검색 결과가 없어요. 다른 이름이나 지역으로 검색해 보세요.`

- 대표 이미지
- 음식점명
- 음식 카테고리
- 주소
- 현재 위치 기준 거리

- 전화번호
- 지도 위치
- 카카오맵 길찾기 버튼
- 저장 버튼

## 8.2 저장 상태

### 미저장

- `저장` 버튼 노출
- 선택 시 그룹 선택 바텀시트 노출

### 저장됨

- `저장됨` 상태 노출
- 선택 시 기존 저장 그룹을 확인하고 변경할 수 있음
- 모든 그룹 선택 해제 후 완료 시 저장 해제 처리

## 8.3 주소 및 지도 위치

- 음식점 주소를 텍스트로 노출한다.
- 주소 선택 시 클립보드에 복사할 수 있다.
- 복사 완료 시 `주소를 복사했어요.` 토스트를 노출한다.
- 지도 영역은 음식점 위치 확인 용도로 제공한다.

## 8.4 카카오맵 길찾기

- 음식점 상세에서 `길찾기` 버튼을 제공한다.
- 선택 시 카카오맵 길찾기로 연결한다.
- 음식점의 위도·경도 또는 주소 정보를 카카오맵에 전달한다.
- 카카오맵 앱이 설치되어 있으면 카카오맵 앱의 길찾기 화면으로 이동한다.
- 카카오맵 앱이 설치되어 있지 않으면 카카오맵 웹 또는 앱 설치 화면으로 연결한다.
- MOO 내부에서는 별도의 경로 탐색 기능을 제공하지 않는다.

### 길찾기 예외

- 위도·경도와 주소가 모두 없으면 길찾기 버튼을 노출하지 않는다.
- 카카오맵 연결에 실패하면 음식점 상세를 유지하고 다음 토스트를 노출한다.

`카카오맵을 연결하지 못했어요. 잠시 후 다시 시도해 주세요.`

- 외부 앱 이동 후 MOO로 복귀하면 기존 음식점 상세 상태를 유지한다.

## 8.5 전화

- 전화번호가 있는 경우에만 전화 버튼을 노출한다.
- 선택 시 전화 연결 확인 팝업을 노출한다.
- 전화번호가 없으면 관련 버튼과 영역을 노출하지 않는다.

## 8.6 정보 미제공 처리

- 대표 이미지 없음: 기본 이미지 노출
- 영업시간 없음: 영역 미노출
- 전화번호 없음: 전화 버튼 미노출
- 주소 없음: 좌표 기반 위치만 제공
- 위도·경도 없음: 지도 영역 및 길찾기 버튼 미노출 가능
- 장소 자체가 삭제됨: 상세 접근 및 신규 저장 제한

# 9. 저장

## 9.1 저장 메인 화면

### 구성

- 화면 타이틀 `저장`
- 전체 그룹 수
- 정렬 드롭다운
- 그룹 리스트
- `새 그룹` 플로팅 버튼
- 하단 내비게이션

### 정렬 기준

- 최근 수정순
- 이름순
- 저장 많은 순

기본값은 `최근 수정순`이다.

## 9.2 그룹 리스트 카드

### 구성

- 대표 이미지
- 그룹명
- 저장 음식점 수
- 참여 멤버 프로필
- 최근 수정일
- 공유 상태

### 정책

- 카드 전체 선택 시 그룹 상세로 이동한다.
- 개인 그룹과 공유 그룹을 동일 목록에서 노출한다.
- 공유 아이콘 또는 멤버 프로필로 공유 상태를 구분한다.
- 대표 이미지가 없으면 기본 이미지를 노출한다.
- 삭제된 그룹은 생성자와 참여 멤버의 목록에서 즉시 제거한다.
- 그룹 삭제 완료 안내, 토스트, 별도 빈 페이지는 제공하지 않는다.

## 9.3 새 그룹 만들기

### 화면 구성

- 타이틀 `새 그룹 만들기`
- 닫기 버튼
- 그룹 대표 이미지
- 그룹명 입력
- 생성 버튼

> 그룹 설명 입력 항목은 제공하지 않는다.

### 그룹 대표 이미지

- 이미지 영역 선택 시 기기 앨범에서 이미지를 등록할 수 있다.
- 이미지 등록은 선택 사항이다.
- 등록 이미지는 그룹 카드와 그룹 상세의 대표 이미지로 사용한다.
- 이미지를 등록하지 않으면 기본 그룹 이미지를 적용한다.
- 업로드 실패 시 기본 이미지를 적용하며 그룹 생성은 계속 가능하다.

### 필수값

- 그룹명

### 그룹명 정책

- 1~30자
- 공백만 입력 불가
- 앞뒤 공백 제거
- 이모지 입력 허용
- 동일한 그룹명 생성 허용

### 생성 버튼

- 그룹명 미입력 시 비활성화
- 유효한 그룹명 입력 시 활성화
- 생성 요청 중 중복 터치 방지
- 저장 화면에서 진입한 경우 생성 완료 후 그룹 상세로 이동
- 음식점 저장 과정에서 진입한 경우 생성된 그룹을 자동 선택하고 저장 플로우를 완료

### 닫기 정책

- 닫기 버튼 선택 시 별도 확인 팝업 없이 이전 화면으로 이동한다.
- 입력한 그룹명과 등록한 이미지는 저장하지 않는다.
- 임시 저장 기능은 제공하지 않는다.
- 다시 진입하면 초기 상태로 노출한다.

### 예외 처리

- 그룹 생성 실패 시 현재 화면과 입력값을 유지하고 오류 토스트를 노출한다.
- 이미지 업로드 실패 시 기본 이미지를 적용한다.
- 네트워크가 없으면 생성 요청을 차단하고 네트워크 안내를 노출한다.

# 10. 그룹 상세 및 공동 편집

## 10.1 그룹 상세 구성

- 그룹명
- 대표 이미지
- 저장 음식점 수
- 참여 멤버
- 친구 초대
- 지도 보기 / 목록 보기
- 음식점 추가
- 그룹 설정

## 10.2 권한

### 그룹 생성자

그룹을 최초로 만든 사용자를 그룹 생성자이자 소유자로 정의한다.

- 음식점 추가·삭제
- 그룹 정보 수정
- 친구 초대
- 멤버 내보내기
- 초대 링크 재발급
- 그룹 삭제

### 일반 멤버

- 음식점 추가·삭제
- 저장 음식점 확인
- 그룹 나가기
- 그룹 삭제 메뉴 미노출
- 그룹 기본 정보 수정 불가

### 비멤버

- 그룹 접근 불가
- 초대 참여 화면 외 그룹 정보 확인 제한

## 10.3 음식점 추가

- 지도 또는 검색으로 음식점을 선택해 현재 그룹에 추가한다.
- 동일 그룹에 동일 음식점을 중복 저장할 수 없다.
- 다른 그룹에 저장된 동일 음식점은 추가할 수 있다.
- 비로그인 또는 권한이 없는 사용자는 추가할 수 없다.

## 10.4 음식점 삭제

- 해당 그룹에서만 제거한다.
- 다른 그룹의 저장 상태는 유지한다.
- 생성자와 일반 멤버 모두 그룹 내 음식점을 삭제할 수 있다.
- 이미 다른 멤버가 삭제한 음식점을 다시 삭제하면 오류 페이지 없이 최신 상태를 반영한다.

## 10.5 그룹 삭제

### 삭제 권한

- 그룹을 최초로 생성한 사용자만 삭제할 수 있다.
- 초대를 통해 참여한 일반 멤버에게는 그룹 삭제 메뉴를 노출하지 않는다.
- 일반 멤버는 `그룹 나가기`만 사용할 수 있다.

### 삭제 플로우

`그룹 상세 → 그룹 설정 → 그룹 삭제 → 삭제 확인 팝업 → 삭제 완료 → 저장 홈`

### 삭제 확인 팝업

**문구**

`그룹을 삭제할까요?`

**보조 문구**

`그룹에 저장된 맛집과 공유 정보가 모두 삭제되며 복구할 수 없어요.`

**버튼**

- 취소
- 삭제

### 삭제 완료 정책

- 삭제 성공 후 `삭제되었습니다` 등의 토스트, 팝업, 완료 페이지를 노출하지 않는다.
- 생성자는 즉시 저장 홈으로 이동한다.
- 삭제된 그룹은 생성자와 모든 참여 멤버의 저장 목록에서 즉시 제거한다.
- 홈의 최근 그룹 및 함께하는 그룹 영역에서도 제거한다.
- 참여 멤버에게 푸시, 팝업, 토스트 등 별도 안내를 제공하지 않는다.
- 삭제된 그룹과 연결된 초대 링크는 즉시 비활성화한다.
- 해당 그룹의 음식점 연결 정보만 삭제하며, 다른 그룹의 동일 음식점 저장 정보는 유지한다.

### 참여 멤버가 그룹 상세를 보고 있는 경우

- 다음 데이터 조회 또는 화면 갱신 시 그룹 상세를 종료한다.
- 별도 삭제 안내 문구 없이 저장 홈으로 이동한다.
- 삭제된 그룹 콘텐츠는 더 이상 노출하지 않는다.

### 삭제된 그룹 재접근

이전 초대 링크, 딥링크 또는 캐시 데이터로 접근하면:

- 삭제 안내 페이지를 노출하지 않는다.
- 저장 홈으로 바로 이동한다.
- 그룹 정보는 노출하지 않는다.

### 삭제 실패

- 그룹을 유지하고 현재 설정 화면에 머문다.
- 생성자에게만 오류 토스트를 노출한다.

`그룹을 삭제하지 못했어요. 잠시 후 다시 시도해 주세요.`

## 10.6 동시 편집

- 서버 최신 상태를 기준으로 처리한다.
- 동일 음식점 동시 추가 시 1건만 유지한다.
- 이미 삭제된 항목의 삭제 요청은 최신 상태로 갱신한다.
- 화면 진입, 앱 포그라운드 복귀, 저장·삭제 완료 시 최신 데이터를 재조회한다.

- 최신 조회 실패 안내
- 재시도 버튼 제공
- 서버 변경 요청 실패 시 이전 상태 복원

## 15.3 세션 만료

- 신규 저장 불가
- 그룹에서 삭제 가능

- 그룹 콘텐츠 미노출

# 21. UI·UX 원칙

1. 홈은 기능 메뉴판이 아니라 최근 활동 중심 대시보드로 구성한다.
2. 음식점 저장은 최대 2단계 안에 완료한다.
3. 지도 이동만으로 결과를 자동 변경하지 않고 `이 지역 검색`을 제공한다.
4. 개인 그룹과 공유 그룹은 동일 구조를 사용하되 공유 상태를 명확히 표시한다.
5. 친구 기능은 별도 소셜 관계가 아니라 공유 그룹 멤버로 한정한다.
6. 빈 화면에는 사용자가 다음에 할 수 있는 행동을 반드시 제공한다.
7. 서버 변경 요청 중에는 중복 터치를 차단한다.
8. 권한이 없는 기능은 노출하지 않거나 비활성화한다.
9. 홈 섹션별 노출 개수를 제한한다.
10. 캐릭터는 핵심 기능 가독성을 방해하지 않는 범위에서 사용한다.

# 24. 상세 연결 플로우 및 예외 처리

## 24.1 공통 이동 정책

- 상위 화면에서 하위 화면은 Push 방식으로 이동한다.
- 그룹 선택, 필터, 공유 등 보조 기능은 Bottom Sheet 또는 Modal을 사용한다.
- 이전 화면으로 돌아가면 검색어, 필터, 스크롤, 지도 위치를 유지한다.
- 입력 화면에서 닫기 또는 뒤로 가기 시 확인 팝업 없이 종료한다.
- 입력값은 저장하거나 임시 보관하지 않는다.

## 24.2 신규 진입

`스플래시 → 온보딩 → 소셜 로그인 → 권한 안내 → 홈`

기존 로그인 사용자는 토큰 확인 후 홈으로 이동한다.

## 24.3 홈 연결

- 프로필 이미지 → 마이
- 검색창 → 통합 검색
- 지역형 Hero Banner → 지정 지역 내주변 지도
- 카테고리형 Hero Banner → 카테고리 적용 내주변 지도
- 특정 음식점형 Hero Banner → 음식점 상세
- 최근 그룹 카드 → 그룹 상세
- 최근 저장 맛집 → 음식점 상세

연결 대상이 없거나 조회에 실패하면 현재 화면을 유지하고 오류 토스트를 노출한다.

## 24.4 검색 연결

- 음식점 결과 → 음식점 상세
- 지역 또는 역명 결과 → 해당 지역 중심 지도
- 음식 카테고리 결과 → 카테고리 필터가 적용된 지도
- 결과 없음 → 검색어 수정 또는 지도에서 찾기
- 상세에서 뒤로 가기 → 검색어, 결과, 스크롤 위치 유지

## 24.5 지도 연결

`내주변 → 지도 이동 → 이 지역 검색 → 마커 갱신 → 마커 선택 → 음식점 요약 카드 → 음식점 상세`

- `이 지역 검색` 전까지 기존 결과를 유지한다.
- 지도 빈 영역 선택 시 음식점 요약 카드를 닫는다.
- 상세에서 뒤로 가면 지도 위치와 선택 마커를 유지한다.
- 지도와 목록 보기 전환 시 동일 검색 조건을 유지한다.

## 24.6 음식점 저장

`음식점 상세 또는 지도 카드 → 저장 → 그룹 선택 → 완료`

그룹이 없는 경우:

`저장 → 새 그룹 만들기 → 그룹 생성 → 생성 그룹 자동 선택 → 저장 완료`

- 일부 그룹 저장에 실패하면 성공한 그룹은 유지하고 실패한 그룹만 재시도한다.
- 네트워크 오류 시 선택 상태를 유지한다.

## 24.7 새 그룹 생성

### 저장 화면에서 진입

`저장 → 새 그룹 → 생성 → 그룹 상세`

### 음식점 저장 중 진입

`그룹 선택 → 새 그룹 → 생성 → 새 그룹 자동 선택 → 음식점 저장 완료`

닫기 선택 시 별도 확인 없이 이전 화면으로 이동하며 입력값은 폐기한다.

## 24.8 그룹 삭제

`그룹 생성자 → 그룹 설정 → 삭제 확인 → 삭제 → 저장 홈`

- 생성자에게 별도 완료 안내를 제공하지 않는다.
- 참여 멤버에게도 별도 알림을 제공하지 않는다.
- 모든 사용자의 홈과 저장 목록에서 그룹을 제거한다.
- 참여 멤버가 삭제된 그룹을 보고 있으면 데이터 갱신 시 저장 홈으로 이동한다.
- 이전 링크로 접근해도 별도 안내 없이 저장 홈으로 이동한다.

## 24.9 카카오맵 길찾기

`음식점 상세 → 길찾기 → 카카오맵 앱 또는 웹 → 길찾기 화면`

- 카카오맵 앱 설치 시 앱으로 이동한다.
- 미설치 시 웹 또는 설치 화면으로 이동한다.
- 위치 정보가 없으면 길찾기 버튼을 숨긴다.
- 연결 실패 시 상세 화면을 유지한다.

## 24.10 공통 네트워크 예외

- 조회 실패: 기존 데이터가 있으면 유지하고 재시도 제공
- 생성·수정·삭제 실패: 성공 상태로 처리하지 않음
- 요청 중 버튼 비활성화 및 중복 터치 방지
- 오프라인 상태의 저장·삭제·그룹 생성은 지원하지 않음

## 24.11 세션 만료

- 로그인 화면으로 이동한다.
- 로그인 완료 후 가능한 경우 기존 요청 화면으로 복귀한다.
- 작성 중 입력값은 복원하지 않는다.
- 삭제되거나 접근 권한이 없는 그룹으로는 복귀하지 않고 저장 홈으로 이동한다.

# 25. 최종 확정 정책 요약

1. 그룹 생성 화면에는 설명 입력란을 제공하지 않는다.
2. 그룹 생성 시 그룹명과 대표 이미지만 설정한다.
3. 입력 화면 이탈 시 확인 팝업을 제공하지 않는다.
4. 작성 내용의 임시 저장 및 복원 기능을 제공하지 않는다.
5. 그룹 삭제는 최초 생성자만 가능하다.
6. 일반 멤버에게 그룹 삭제 메뉴를 노출하지 않는다.
7. 그룹 삭제 후 생성자와 참여 멤버 모두에게 완료 안내를 제공하지 않는다.
8. 삭제된 그룹은 모든 관련 화면에서 제거한다.
9. 삭제된 그룹 링크 접근 시 안내 없이 저장 홈으로 이동한다.
10. 음식점 길찾기는 카카오맵 앱 또는 웹과 연동한다.
