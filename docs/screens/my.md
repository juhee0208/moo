## 1. 마이 — `MOOHAPP_MY_HOME`

```text
+-----------------------------------+
|                    [🔔•] [⚙️]     |
|     [프로필 이미지 ✎]             |
|     {닉네임}                      |
|     MOOH와 함께 맛집 찾기          |
| [ mooh: 초대장                  > ]|
| [ 친구 초대하기                > ]|
| 공지사항 (블로그)              >  |
| FAQ                            >  |
| 이용약관                       >  |
| 개인정보처리방침               >  |
| 협업 문의                      >  |
| 로그아웃                          |
| 운영자 이름 · 문의 이메일 (D62)   |
+-----------------------------------+
| 홈 | 그룹 | 마이   (MVP 3탭, D51)  |
+-----------------------------------+
```

| # | 영역 | 동작 |
|---|---|---|
| 1 | 상단 아이콘 | **알림(🔔) — 환경설정(⚙️) 왼쪽.** 안 읽은 알림이 있으면 뱃지. 🔔 → 알림함, ⚙️ → 환경설정 |
| 2 | 프로필 | 이미지(수정 아이콘), 닉네임, 서브 문구. 이미지 없으면 기본 프로필. 수정 아이콘 → 프로필 수정 |
| 3 | `mooh: 초대장` | 초대장 풀팝업 (`invite.md`). 대기 초대 개수 뱃지 ⚠️ 채택 여부 확인 |
| 4 | `친구 초대하기` | 앱 추천 링크를 OS 공유 시트로 공유. **그룹·친구 관계와 무관** |
| 5 | 메뉴 | 공지사항 / FAQ / 이용약관 / 개인정보처리방침 / 협업 문의 / 로그아웃. **공지사항 → 네이버 블로그 공지 카테고리(앱 안 브라우저)** (D57), FAQ → `MOOHAPP_FAQ` (6절), 이용약관 · 개인정보처리방침 → 앱 안 문서(블로그 글과 같은 내용, D58), **협업 문의 → 인스타그램 DM 또는 전용 이메일(메일 앱 없으면 주소 복사)** (D59) |
| 6 | 푸터 | 운영자 이름 · 문의 이메일 + 정책 링크 (D62) |

- 로그아웃 → `MOOHAPP_DIALOG_LOGOUT_CONFIRM`

## 2. 알림함 — `MOOHAPP_NOTIFICATIONS`

푸시 알림은 없다. 앱 안에서만 보이는 알림 목록이다.

```text
+-----------------------------------+
| <             알림                |
| • 백주희님이 '데이트 코스' 그룹에  |
|   초대했어요.            방금 전  |
|   '회사 근처' 그룹이 삭제되었어요. |
|                            어제   |
|   '까치산 맛집' 그룹에서          |
|   내보내졌어요.          3일 전   |
+-----------------------------------+
```

| 알림 종류 | 터치 시 |
|---|---|
| 그룹 삭제 (`NOTI_GROUP_DELETED`, 사유 변수) | 이동 없음 |
| 내보내짐 (`NOTI_MEMBER_REMOVED`) | 이동 없음 |
| 폐업 맛집 자동 삭제 (`NOTI_PLACE_AUTO_REMOVED`, D56) | 이동 없음 |

- 문구: `05-messages.md` 2절
- 최신순. 안 읽은 항목 강조(•). 알림함 진입 시 전부 읽음 처리
- 그룹 삭제·강퇴 안내는 **알림함에만** 쌓고 모달은 띄우지 않음
- 보관 기간·최대 개수는 미정 (`open-questions.md`). 폐업 맛집 자동 삭제 알림은 D56
- 0건 → 빈 화면 문구

## 3. 환경설정 — `MOOHAPP_SETTINGS`

```text
+-----------------------------------+
| <           환경설정              |
| 회원 탈퇴                      >  |
+-----------------------------------+
```

- **알림 설정 메뉴 없음** (푸시 없음)
- 회원 탈퇴는 환경설정 바로 아래 1단계로 둔다 (앱스토어 심사: 앱 안에서 쉽게 찾을 수 있어야 함)
- 다른 메뉴 추가 여부 미정 (`open-questions.md`)

## 4. 프로필 수정 — `MOOHAPP_PROFILE_EDIT`

- 프로필 이미지, 닉네임 변경
- 닫기·뒤로 시 확인 없이 입력값 폐기

## 5. 회원 탈퇴 — `MOOHAPP_WITHDRAW`

- 탈퇴 안내 → `MOOHAPP_DIALOG_WITHDRAW_CONFIRM` (내가 만든 그룹 수 표시)
- 처리:
  - 개인 데이터 지체 없이 파기
  - Apple 토큰 revoke + 카카오 · 네이버 · Google 연결 끊기 (D61)
  - 내가 만든 그룹 자동 삭제 → 남은 멤버 알림함 (`NOTI_GROUP_DELETED`, reason=`OWNER_WITHDRAWN`)
  - 참여 중인 그룹에서 자동으로 빠짐
- 복구 불가, 입력 중 임시 저장 없음
- 완료 후 로그인 화면

## 6. 공지사항 · FAQ — `MOOHAPP_FAQ`

> **D57 (2026-11-19)**: 공지사항은 앱 화면을 만들지 않고 **네이버 블로그 공지 카테고리 링크**로 연다. 아래 공지사항 목록 · 상세 화면은 쓰지 않고 **FAQ 화면만** 만든다 (자주 묻는 질문을 운영자가 원격 설정 JSON에 추가).

콘텐츠는 원격 설정 JSON에서 읽는다. 어드민 없이 개발자가 수정한다 (D50, `07-dev-design.md` 12절).

```text
[공지사항 목록]                     [FAQ]
+-------------------------------+   +-------------------------------+
| <          공지사항            |   | <            FAQ              |
| 📌 MOOH 출시 안내    11.20      |   | [그룹] 그룹은 몇 개까지...  v |
|    서비스 점검 안내   11.18    |   |   답변 본문                   |
+-------------------------------+   | [초대] 초대 링크가 만료...  > |
                                    +-------------------------------+
```

| 화면 | 동작 |
|---|---|
| 공지사항 목록 | 고정(`pinned`) 먼저, 이후 게시일 내림차순. 터치 → 상세 |
| 공지사항 상세 | 제목, 게시일, 본문(마크다운) |
| FAQ | 카테고리 + 질문 목록, 터치 시 아코디언으로 답변 펼침 |

- 원격 설정 로드 실패 시 마지막으로 받은 내용 표시, 없으면 빈 화면 ⚠️`등록된 공지사항이 없어요.` / ⚠️`등록된 FAQ가 없어요.`
