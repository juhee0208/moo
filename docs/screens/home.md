# 화면: 홈 — `MOOHAPP_HOME`

관련 정책: `02-policies.md` 1절(노출 개수), 6절(공유 배지)

```text
+-----------------------------------+
| WELCOME                    [프로필]|
| {닉네임}님 👋        [모오 캐릭터] |
| [ 지역이나 음식점을 검색해 주세요 ]|
| [        Hero Banner  ●○○      ]  |
| 최근 그룹                    더보기|
| [그룹][그룹][그룹] ->             |
| 최근 저장한 맛집             더보기|
| [IMG] 맛집명 #그룹태그    [저장]  |
| [IMG] 맛집명 #그룹태그    [저장]  |
| [나만의 맛집 친구랑 같이 공유해볼까요?]|
| 함께하는 MOOH 친구                 |
| (프로필) (프로필) (프로필) ->     |
| 사업자 정보 / 약관 / 개인정보      |
+-----------------------------------+
| 홈 | 그룹 | 마이   (MVP 3탭, D51)  |
+-----------------------------------+
```

알림 아이콘은 홈에 두지 않는다 (마이에만 있음).

## 구성 (위에서부터)

| # | 영역 | 구성 | 동작 |
|---|---|---|---|
| 1 | 웰컴 헤더 | WELCOME, 닉네임, 캐릭터, 프로필 | 닉네임 말줄임. 프로필 미등록 시 기본 이미지. 프로필 → 마이 |
| 2 | 검색창 | 플레이스홀더 `지역이나 음식점을 검색해 주세요` | 터치 → 통합 검색 (홈에서 키보드 열지 않음) |
| 3 | Hero Banner | 배경 이미지, 라벨, 타이틀, 서브 정보, 페이지 인디케이터 | 캐러셀. 맛집형 → 상세, 외부 링크형 → 브라우저. 운영자가 2~3개 등록, 대가 받은 배너는 "광고" 표시, 이미지는 이용권 있는 것만 (D60). 콘텐츠는 원격 설정 JSON에서 로드(D50, `07-dev-design.md` 12절). 기간 밖·연결 대상 없는 배너는 노출 안 함. 이미지 실패 시 기본 배경+텍스트 |
| 4 | 최근 그룹 | 가로 스크롤 카드 최대 5개: 커버, 그룹명, 멤버 수·맛집 수, 공유 배지 | 최근 수정순. 카드 → 그룹 상세, [더보기] → 그룹 홈 |
| 5 | 최근 저장한 맛집 | 세로 리스트 최대 5개: 기본 이미지/카테고리 아이콘, 맛집명, 카테고리·주소, 저장된 그룹 태그, 저장 아이콘 | 최근 저장순. 카드 → 맛집 상세, 그룹 태그 → 해당 그룹 상세, 저장 아이콘 → 그룹 선택 BS, [더보기] → 그룹 홈 |
| 6 | 공유 유도 배너 | 캐릭터 인라인 배너 `나만의 맛집 친구랑 같이 공유해볼까요?` | 그룹 만들기/초대 유도 |
| 7 | 함께하는 MOOH 친구 | 최대 6명: 프로필, 닉네임, 함께 참여 중 그룹 수 | 최근 공동 활동순. 터치 → 함께하는 그룹 1개면 그 그룹 상세, 2개 이상이면 `MOOHAPP_FRIEND_GROUPS_BS` |
| 8 | 푸터 | 서비스명(MOOH), 운영자 이름, 문의 이메일, 이용약관, 개인정보처리방침 (사업자 없는 동안, D62) | 텍스트 링크 → 블로그 글 또는 앱 안 문서 (D58) |
| 9 | 하단 탭 | 홈 활성 | |

- 맛집명·카테고리·주소는 저장된 장소 ID로 실시간 재조회 (`04-external-api.md`)
- 섹션별 독립 로딩 + 스켈레톤
- 0건 처리: `05-messages.md` 3절 빈 화면 문구
- 친구 정의: 나와 같은 그룹에 참여 중인 멤버를 중복 없이 모음. "친구 초대하기"(앱 추천)로 가입한 사람은 해당 없음

## 함께 참여 중인 그룹 바텀시트 — `MOOHAPP_FRIEND_GROUPS_BS`

```text
+-----------------------------------+
| (프로필) {닉네임}님과 함께하는 그룹 [X]|

|       멤버 3 · 맛집 23            |
| [IMG] 회사 근처                   |
|       멤버 8 · 맛집 41            |
+-----------------------------------+
```

- 그룹 카드 → 그룹 상세
